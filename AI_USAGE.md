## AI Tools Used

The group used the following AI tools:

- ChatGPT
- Claude
- Gemini

Different group members used different tools depending on personal preference and availability. All four group members used AI support at some point during the project.

## Purpose of AI Use

AI was mainly used for two purposes:

**Code debugging**

- We wrote the baseline code ourselves.
- When errors occurred, we asked AI tools to help identify possible causes and suggest fixes.
- Suggested fixes were tested in the notebook before being accepted.

**Graph styling**

- We used AI to help improve the graphs' visual style with specific requirments we wanted to be fulfilled.
- Used it as a source of information for the country mapping regarding norms across different libraries

**Report grammar checking**

- We wrote the report and presentation content ourselves.
- AI tools were used to check grammar.
- No report or presentation text was directly written by AI.

## Prompt Summaries

Examples of the types of prompts we used include:

- Asking AI to explain why a piece of code produced an error message.
- Asking AI to suggest a fix for code that was not running correctly or got an error.
- Asking AI how to improve the style of a graph.
- Asking AI to check report text for grammar.
